# Changing Priorities

In this mission, objectives are ever changing and armies adapt to constantly changing circumstances.

## Victory conditions

The following Mission Objectives are used in this mission:

### Primary Mission Objectives

- This mission includes 6 objectives each worth 2 VP.

### Secondary Mission Objectives

- Slay the Warlord (4)
- Giant Killer (2)
- Last Man Standing (2)
- First Strike (2)


## Mission special rules

This mission uses the **Changing Priorities Mission**, **Reserves**,
and **Counter Offensive** Mission Special Rules.

### Changing Priorities Mission

During setup, each player should alternate placing a total of 6 objectives.

Each objective must be placed more than 6" from any table edge and 12" from any other objective.

At the start of each battle round, randomly select 2 objectives - the first is worth +1VP to whoever scores it during the round, the second is worth -1VP to whoever holds it.
