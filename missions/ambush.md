# Ambush

The defender's army has been moving to the front line, but
thanks to bad reconnaisance the attacker has been able to set
up an ambush on the road.

## Victory conditions

The following Mission Objectives are used in this Mission:

### Primary Mission Objectives

- Attacker: Crush the Enemy
- Defender: Escape the Trap

**Crush the Enemy**
The attacker scores 2 Victory Points for every enemy unit they
destroy. Units with the Vanguard (X) special rule score an additional
X Victory Points for destroying an enemy unit.

**Escape the Trap**
The defender scores 2 Victory Points for every enemy unit
they destroy. In addition, units in the defender's army are permitted
to move off of the table edge specified as the Escape Route (see
the special rules below). Any unit that moves off the table through
the Escape Route is with 2 Victory Points.

### Secondary Mission Objectives

- Slay the Warlord (2)

## Mission Special Rules

This Mission uses the **Ambush Mission**, **Hidden Deployment**, **Random Game Length**,
and **Reserves** Mission Special Rules.

### Ambush Mission

The attacker is lying in wait for the defender's army to spring their trap.
This has the following effects:

- Skip the Select Deployment Map step. Instead, both players roll off and the winner
  chooses one short table edge to be the Escape Route. The deployment map is as follows,
  oriented using the chosen Escape Route:

  ![Ambush Deployment Map]({{site.baseurl}}/assets/img/ambush-deployment.png)

- During the Declare Mission Reserves step, the attacker must roll a D6 for each
  unit in their army. On a 1 or 2, that unit must be placed in Reserves. The
  attacker may then place any additional units in Reserve that they wish.
  If the attacker rolls 1 or 2 for all of their units, then they must select one
  unit to deploy on the table.

  The defender may not place any units in Reserve.

- During the Deploy Armies step, the attacker deploys first using the rules for Hidden
  Deployment. The defender then deploys their units in their deployment zone.

The attacker automatically takes the first turn.
